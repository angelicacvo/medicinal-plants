🎯 CÓMO USAR ESTA DOCUMENTACIÓN
================================================================================

PASO 1: LEER PRIMERO
--------------------
1. README.md - Para entender el proyecto
2. docs/COMO_USAR_DOCUMENTACION.md - Para saber cómo proceder

PASO 2: CONFIGURAR KANBAN
--------------------------
1. Ir a https://github.com/users/angelicacvo/projects/6/views/1
2. Abrir docs/KANBAN_GUIDE.md
3. Copiar cada plantilla de Issue (1-5)
4. Crear los 5 issues en GitHub
5. Agregarlos al proyecto Kanban

PASO 3: COMENZAR DESARROLLO
----------------------------
Para cada día (1-5):
1. Abrir docs/kanban-issues/dia-X-*.md
2. Seguir las tareas en orden
3. Marcar checkboxes en docs/CHECKLIST.md
4. Usar docs/QUICK_REFERENCE.md para comandos
5. Verificar criterios de aceptación
6. Actualizar Kanban en GitHub

PASO 4: VERIFICACIÓN
---------------------
Al final de cada día:
1. Ejecutar npm run test
2. Ejecutar npm run build
3. Probar endpoints
4. Hacer commit siguiendo Conventional Commits
5. Mover issue a "Completado" en Kanban
